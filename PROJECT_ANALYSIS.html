🔄 4. Frontend-Backend Communication

User Registration Flow

pages/register.php (HTML Form) ↓ POST [email, password] ↓ includes/db.php (Hash & Validate) ↓ INSERT INTO users table ↓ session_start() + $_SESSION['user_id'] ↓ Redirect to index.php

Product Display Flow

index.php (Page Load) ↓ Check $_SESSION['user_id'] ↓ includes/db.php (SELECT all products) ↓ Loop through results ↓ Display product cards

Add to Cart Flow

index.php (Add to Cart Button) ↓ POST [product_id] to pages/cart.php ↓ includes/db.php (SELECT from cart) ↓ If exists: UPDATE quantity ↓ If new: INSERT into cart

Admin Product Management Flow

admin/add_product.php (Form + File) ↓ POST [name, price, description] + FILE [image] ↓ move_uploaded_file() to images/ ↓ includes/db.php (INSERT into products) ↓ Success message

🗄️ 5. Database Structure (Read-Only)

Users Table

CREATE TABLE users ( id INT PRIMARY KEY AUTO_INCREMENT, email VARCHAR(255) UNIQUE NOT NULL, password VARCHAR(255) NOT NULL, role ENUM('user', 'admin') DEFAULT 'user', created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );

Products Table

CREATE TABLE products ( id INT PRIMARY KEY AUTO_INCREMENT, name VARCHAR(255) NOT NULL, price DECIMAL(10, 2) NOT NULL, description TEXT NOT NULL, image VARCHAR(255), created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );

Cart Table

CREATE TABLE cart ( user_id INT NOT NULL, product_id INT NOT NULL, quantity INT DEFAULT 1, added_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, PRIMARY KEY (user_id, product_id), FOREIGN KEY (user_id) REFERENCES users(id), FOREIGN KEY (product_id) REFERENCES products(id) );
